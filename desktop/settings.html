Connect to your picks

The app reads the weekly picks straight from your private GitHub repo. It needs a read-only token:

  1. Open GitHub → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → your Stocks repo.
  3. Permissions → Repository → Contents: Read-only. Pick an expiry (up to 1 year).
  4. Generate, copy the token and paste it below.
